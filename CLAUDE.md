# Vibear

Find the clothes you saw on social media: upload a photo → YOLO detects garments → Google Lens (SerpApi) finds products → FashionCLIP orders them by similarity.

## Layout
- `apps/api`: FastAPI (Python). `create_app()` in `app/main.py` takes injectable fakes; tests never load models or call SerpApi.
- `apps/web`: Next.js 16 App Router + Tailwind 4. The browser calls `/api/*`, proxied to the API by `next.config.ts`.
- `scripts/`: cross-platform Node scripts behind `npm run setup` / `npm run dev`.

## Commands (repo root)
- `npm run dev`: API :8000 + web :3000. `scripts/api.mjs` restarts the API on `.py` changes. Don't switch it to `uvicorn --reload`: on Windows that sends CTRL_C_EVENT to the whole console and kills Next too.
- `npm run check`: run before any commit. API tests, typecheck, lint (`--max-warnings 0`), build, Playwright.
- Search without a SerpApi key: `DEMO_SEARCH=true` in `apps/api/.env`.

## Conventions
- Never copy images you don't own (Pinterest, Instagram) into the site or the repo: use the Pinterest embed (`NEXT_PUBLIC_PINTEREST_*`) or the gitignored `apps/web/local-photos/` (`npm run photos`, dev only).
- Front-end work: use the `vibear-design` skill (`.claude/skills/vibear-design/`); anything animated also uses `vibear-motion`. Tokens and motion primitives live in `apps/web/src/app/globals.css`.
- Routes: `/` is the landing (story + motion), `/scan` the scanner, `/look/[id]` results, `/saved` the closet ("placard"), `/creditos` photo credits.
- Landing: `components/landing/Story.tsx` is the scroll-story hero (`.story-*` in `globals.css`); the other sections are in `Sections.tsx` and alternate black and `.page.theme-light` white. The Pinterest/Instagram/TikTok marks (`SocialLogos.tsx`) appear in their colours only in the hero, behind the headline, with the non-affiliation line in the footer. `local-photos/destacada/` sets the hero photo in dev.
- Responsive check: phones, both iPad orientations, a phone held sideways and a 768px-tall laptop, by screenshot. The overflow test doesn't catch overlaps.
- `cacheComponents` is on: visited pages stay mounted but hidden (React Activity), so the DOM holds hidden copies. In Playwright use `getByRole` or check visibility. Anything reading the URL (`usePathname`, `params`) goes inside `<Suspense>`. Every page wraps its content in `PageTransition`.
- Closet: localStorage plus an anonymous backup (`/v1/closet`, HttpOnly cookie, newest copy wins). No login: the user chose this. E2E tests must mock `/api/v1/closet` (`mockApi` does), never hit a real API.
- Speed: judge with `npm run preview` (production), not `npm run dev`. Measure with a 4x CPU throttle before and after a perf change.
- `apps/web/src/lib/landing.ts`, `apps/web/public/landing/` and `apps/api/app/demo_catalog/` are generated by `apps/api/scripts/build_landing_assets.py`; don't edit them by hand.
- Nearby shops: `app/places.py` (Nominatim only; Overpass was dropped because its public instances were down). Respect Nominatim's policy: one request per search, honest User-Agent, results cached.
- Code, comments and README in English; UI copy in Rioplatense Spanish (`lib/labels.ts`, `MESSAGES` in `lib/api.ts`).
- Image ids are 16 hex characters of the JPEG's sha256 (content-addressed, so caching works).
- Next 16 differs from older versions: check `apps/web/node_modules/next/dist/docs/` before using an API you're unsure of (see `apps/web/AGENTS.md`).
